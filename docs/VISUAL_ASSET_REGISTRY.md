# Q Workwear | Production visual asset register
**Status: NEW PRODUCING ASSETS NOT VERIFIED.** All IDs below refer to proposed shots from [Photoreal image-production brief](PHOTOREAL_Q_WORKWEAR_IMAGE_PRODUCTION_2026-10-19.md). Existing geometric art is archived reference only, not acceptable final photography.

This register MUST be filled as each new source/photographic image is produced or obtained. No "approved" without a factual source check and owner's actual approval.

## State machine

- IDEA: prompt only, no image exists.
- CANDIDATE: produced/obtained, needs realism and rights inspection.
- REJECTED: failed garment/brand/rights/crop review; retain reason.
- EDITED: image composited with exact Q logo, needs review.
- SELECTED_INTERNAL: design owner prefers; no client/publication approval implied.
- APPROVED_PUBLIC: written authorization from relevant image rights holder and owner, visual/copy QA passed.
- BLOCKED_RIGHTS: permissions unclear.
- BLOCKED_TOOLS: no working photoreal-capable generator or original photo.
- ARCHIVED_ABSTRACT: replaced prototype image, not final media.

## Mandatory metadata per asset
`id, target_path, generator_or_original_source, source_slide_if_any, actual_original_path, model/version_if_generated, prompt_id, seed_if_available, people_rights, third_party_brand_rights, image_class(real_Q_commission|illustrative_concept), business_approval, crop, logo_asset, compositing_method, master_path, output_dimensions, output_bytes, alt_text, placements, status, rejection_reason, reviewed_by, reviewed_at`.
